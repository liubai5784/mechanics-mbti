# 力学 MBTI

可在微信浏览器打开的12题校园趣味测试，纯静态，无后端、无需登录、不上传答案。

## 功能

- E/I、S/N、T/F、J/P 每维3题，二选一，多数票生成16种类型。
- 16种类型映射到8门力学课程，包含完整课程图鉴。
- 支持返回修改、重新测试、复制结果链接和微信菜单分享提示。
- 适配手机屏幕，使用系统无衬线字体。

## 运行与发布

直接打开 `index.html` 即可本地试用。GitHub Pages 发布源为 `main` 分支根目录，网页不需要构建。

题目、类型文案和课程映射位于 `data.js`，图片位于 `assets/`。分享链接仅携带类型，不包含答题记录。刷新会清空答题进度。
